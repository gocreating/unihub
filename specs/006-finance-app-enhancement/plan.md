# Implementation Plan: Finance App Enhancement

**Branch**: `006-finance-app-enhancement` | **Date**: 2026-05-29 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `specs/006-finance-app-enhancement/spec.md`

## Summary

Enhances the Finance domain across three dimensions:
(1) **Universal numeric formatting** — comma separators, right-alignment, decimal-point alignment applied to all finance table columns that show amounts;
(2) **Balance sheet detail enrichment** — a switchable pie-chart visualization card (three chart types) plus a flexible multi-dimensional tree aggregation section added above the existing account table;
(3) **Balance sheet list enrichment** — a switchable time-series chart card (net worth trend + stacked balance breakdown) added above the existing PageTable;
(4) **Form input polish** — currency-symbol prefix and right-aligned entry on all monetary inputs in create/edit forms.

All changes are **frontend-only**. Existing API data is sufficient; no new backend endpoints are required.

**Storage**: N/A — frontend-only feature; no database changes

**Testing**: Vitest + React Testing Library (frontend)

**Target Platform**: Desktop/tablet browser (Chrome, Safari, Edge)

**Project Type**: Single-page web application (SPA)

**Performance Goals**: All charts render within 300 ms of data availability; parallel balance fetches for stacked chart complete within 1 s for ≤50 sheets

**Constraints**: `strict: true` TypeScript; zero ESLint warnings; every user-visible string i18n'd in both `en-US` and `zh-TW`

**Scale/Scope**: Personal-use tracker; typically < 50 balance sheets, < 20 accounts per sheet
